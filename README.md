## 排行榜最该写、却几乎不写的三件事

高防服务器的价格主要由防御峰值决定，品牌排在后面。同一家机房，30G 防御和 300G 防御的月租能差四五倍，这件事在任何一份“十大品牌”里都看不到。除了那个 G 数，还有三个细节决定了这笔钱花得值不值。

**一、这个“XX G”是保底还是弹性。** 保底防御是包年包月预付的固定额度，弹性防御是按天计费的后付费额度，只有攻击峰值超过保底时才开始计费。腾讯云 DDoS 高防 IP 的结构可以拿来当参照（2022 年版计费规则，仅用于说明保底与弹性的结构差异，非当前报价）：保底带宽预付费且只升不降，弹性防护按当天最高攻击峰值扣减保底后的区间计费，没触发就不收钱。同一句“100G 防御”，写的是保底 100G，还是保底 30G 加弹性 70G，成本完全是两回事。

**二、带宽是独享还是共享。** 香港高防服务器报价 30G 防御月租 ¥1,610 的那一档，带宽只给到 2M。够清洗，不够跑业务。低价套餐经常是防御数字好看、带宽卡死，攻击没打死你，正常流量先堵住了。

**三、超过清洗能力之后会发生什么。** 这是最容易被跳过的一项。机房处理不了的时候会把 IP 直接黑洞掉，攻击流量和正常流量一起丢弃。黑洞时长从 30 分钟到几小时不等，能不能提前解除、能不能加白名单，各家规则不一样。

国内主流服务商在中等配置（E5 CPU / 32G 内存 / 500G SSD / 50M 独享带宽）这个前提下，报价大致按防御峰值分成四档。

香港的报价明显比这个区间高。同样 30G 防御，香港高防服务器报 ¥1,610/月，带宽只给 2M，防护域名 20 个、转发端口 50 个。原因不难猜：香港带宽本身就贵，高防又以大流量清洗为主，带宽成本直接压在月租上。拿香港高防服务器去和美国高防云比“谁便宜”没什么意义，美国那边 30G 防御、1 核 1G、5M 带宽、不限流量的高防云报 ¥588/月，是另一种产品。

**以上竞品数字均为资料发布时点的报价，来自不同年份的第三方整理，仅作量级参照，请以各商家当前页面为准。**

还有一种更常见的混淆：高防 IP 和高防服务器。前者是代理层清洗，你的服务器不动，流量先进清洗节点再回注；后者是机房链路层自带防御。两者的价格结构完全不同，放在一张表里比价只会得出错误结论。香港 10G 防御的高防 IP 首月 ¥2,400（同为资料发布时点报价），不等于“10G 防御只要两千四”。

## 保底、弹性和黑洞：攻击真来的时候会发生什么

绝大多数标着“高防”的服务器，在攻击超过某个阈值后都会走黑洞这条路，区别只在于阈值多高、黑洞多久、能不能人工干预。

GoMami 的官方文档把这件事写得很直白。所有实例默认带 best-effort 基础流量清洗，免费，不需要任何配置；更强的 600 Gbps 专业清洗属于付费增值服务，需要联系客服或在网站确认。黑洞的触发条件是“大规模 DDoS 攻击影响到同网段其他客户”，此时系统对该 IP 自动执行黑洞，持续 30 到 60 分钟，自动解除，**无法人工干预**。黑洞期间进出流量全部丢弃，服务不可用。

这三个参数值得单独记下来，因为它决定了一次真实攻击的业务损失是“卡一会儿”还是“停一小时”。拿着同样三个问题去问任何一家报高防的商家都不会亏：清洗触发阈值是多少？超过之后黑洞多久？能不能提前解除？

攻击类型上，GoMami 文档列的是 L3/L4 层的 UDP Flood、SYN Flood、ACK Flood、ICMP Flood、DNS Amplification、NTP Amplification，以及 L7 层的 HTTP Flood、CC 攻击和 Slowloris。L7 的具体策略随节点和防护等级变化。
